# py
# Шпаргалка Python
# PY / CORE

Статический сайт-шпаргалка по Python для middle-разработчика. Материал разбит
по дереву тем: основа языка, поток выполнения, стандартная библиотека и
подключаемые фреймворки. У ключевых тем есть короткие пояснения и рабочие
примеры; расширенные модули пока ведут на страницы-заглушки.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте в браузере `http://localhost:8000`. Сайт не требует установки
зависимостей или сборки.

### Навигация

* Содержание находится в левой панели, а вложенное оглавление открытой темы — справа.
* Поиск фильтрует пункты дерева; фокус на поиск — `Ctrl+K` / `⌘K`.
* Кнопка «копировать» в блоке кода помещает пример в буфер обмена.
